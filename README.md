# Scam With Your Friends — Famous Callers

Adds 20 fan-made callers with character-specific personalities, original opening lines, game-style floating-head portraits and 20 distinct synthetic voice samples. Works with the standard AI backend or the separate Ollama mod. Tested with game **0.1.74-swyf**. The voices are character-style approximations, not official performances.

## Setup

1. Close the game and run [setup.exe](https://github.com/LennonAmos/scam-with-your-friends-famous-callers/releases/latest).
2. Reopen the game and host a lobby. The pack joins the built-in caller pool, and setup adds it to an existing daily lineup.
3. For multiplayer, everyone should install the same pack version so names and portraits resolve correctly.

For occasional Rick burps, also update the [Ollama mod](https://github.com/LennonAmos/scam-with-your-friends-locally-running-ai/releases/tag/v1.0.4) to **v1.0.4+**. Players do not need voice-generation tools.

Callers: Homer Simpson, Marge Simpson, Mr. Burns, Peter Griffin, Stan Smith, Roger, Philip J. Fry, Turanga Leela, Bender, Rick Sanchez, SpongeBob SquarePants, Patrick Star, Squidward Tentacles, Mr. Krabs, Shrek, Donkey, Walter White, Saul Goodman, Michael Scott, Dwight Schrute.

To remove the pack, close the game and run `setup.exe --uninstall`. Other callers are preserved. After a game update, rerun setup if the pack is missing.
